# Construction Company Website

A static marketing website for a Central New York construction company, built
with Next.js (App Router), TypeScript, and Tailwind CSS. Every page is
statically generated at build time, so hosting stays inexpensive. No database,
no authentication.

> **All content is placeholder content.** Every value marked `[PLACEHOLDER]`
> — company name, contact details, services, projects, and especially the
> Certifications page — must be replaced with real, verified information
> before launch. No real certifications, licenses, clients, or completed
> projects are included.

## Getting started

```bash
npm install
npm run dev     # develop at http://localhost:3000
npm run build   # production build in ./.next (all pages prerendered)
```

## Replacing placeholder content

- **`lib/content.ts`** — single source of truth for all site content:
  company name, contact info, services, projects, certifications, and the
  about-page copy. Edit this file first.
- **`public/images/`** — placeholder SVGs generated by
  `scripts/generate-placeholders.mjs`. Replace with real photos (keep the
  filenames or update the paths in `lib/content.ts`). Prefer WebP/JPG sized
  close to display size, since static export serves images unoptimized.
- **`siteConfig.url`** in `lib/content.ts` — set your production domain so
  sitemap.xml, robots.txt, and Open Graph metadata resolve correctly.
- The hero headline/intro on `app/page.tsx` and page descriptions contain a
  few inline `[PLACEHOLDER]` strings as well.

## Pages

| Route | Purpose |
| --- | --- |
| `/` | Hero, services overview, featured projects, company intro, quote CTA |
| `/services/` | Full services list |
| `/projects/` | Project portfolio (sample slots) |
| `/about/` | Company story and values |
| `/certifications/` | Credential slots — **do not publish until verified** |
| `/contact/` | Quote-request form + contact details |

The contact form opens the visitor's email client (mailto) so it works with
no backend. To receive submissions directly, connect a form service (e.g.
Formspree) or an AWS SES endpoint in `components/ContactForm.tsx`.

## Deploying

### AWS Amplify Hosting (current setup)

The repo is connected to Amplify's Next.js hosting integration:

- Build command: `npm run build`
- Output directory: `.next` (per AWS docs for Next.js 14+ apps, including
  fully static ones)

Every push to `main` triggers a deploy. All pages are prerendered at build
time and served from Amplify's CDN.

### S3 + CloudFront (alternative)

1. Add `output: "export"` to `next.config.ts` so `next build` writes a plain
   static site to `out/`.
2. `npm run build`
3. Sync `out/` to your S3 bucket: `aws s3 sync out/ s3://YOUR_BUCKET --delete`
4. Point CloudFront at the bucket. Because `trailingSlash` is enabled, pages
   are emitted as `folder/index.html`; configure CloudFront to rewrite
   `.../` to `.../index.html` (a small CloudFront Function or the S3 website
   endpoint handles this). Set `404.html` as the error page.
